Song Library

songs.json is this library's save file, sitting next to this page in your GitHub repo. Changes you make here (adding songs, editing, importing) are kept automatically in this browser, but that's only local to this device — click Download songs.json and commit that file to your repo to save your changes for good and see them anywhere else. Reload songs.json pulls the committed file back in, replacing what's in this browser.

Export/Import CSV is for bulk-adding songs from a spreadsheet — open the exported CSV in Google Sheets as a template (columns: Title, Section, Chords, Lyrics, Notes, Tags, Layout, Text Size %, Chord Size %; put each chord row on its own line inside a "Chords" cell, chords separated by commas, e.g. "C, Am, F, C"; Tags is a comma-separated list, e.g. "bluegrass, uptempo"). A song with multiple sections gets one extra row per section — leave Title blank on those rows. Importing never overwrites an existing song: if a title matches one you already have, the new one is added with "(copy)" on the end so you can find it later (search "copy") and decide what to keep. Remember to Download songs.json afterward to make an import permanent.

    Gig Setlist

    Save updates the gig list currently loaded below (or prompts for a name if you haven't loaded one). Save as new list always creates a separate new saved list, so you can load an old setlist as a starting point for a new gig and save your changes under a new name without touching the original. As with songs.json, changes are kept in this browser automatically, but download setlists.json and commit it to your repo to save your gig lists for good and see them on other devices.
